LOCAL START

팀원 로컬 실행 방법

각자 환경 필요

1. 저장소 받기

git clone https://github.com/hajoonleeim-design/PASSBOX.git
cd PASSBOX

이미 clone한 팀원은 최신 변경사항만 받으면 됩니다.

git pull origin main

2. 백엔드 실행

cd backend
Copy-Item .env.example .env
notepad .env
.\.venv\Scripts\python.exe create_tables.py
.\.venv\Scripts\python.exe seed_demo_user.py
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

PostgreSQL이 실행 중이어야 합니다. 시드 계정 비밀번호는 실행 중 직접 입력합니다.

3. 프론트엔드 실행

cd frontend\PASSBOX-ver.0.1
npm ci
Copy-Item .env.example .env.local
notepad .env.local
npm run dev

.env.local에는 VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1을 설정합니다.

4. 확인 주소

  • 프론트: http://127.0.0.1:5173/
  • Swagger: http://127.0.0.1:8000/docs
  • 생존 확인: /api/v1/health
  • DB 준비 확인: /api/v1/health/ready

DEMO CHECKLIST

시연·검증 순서

  1. 시드 사용자로 로그인하고 홈 화면과 역할별 메뉴를 확인합니다.
  2. 민감하지 않은 test.pdf를 업로드합니다.
  3. 검사·추출·스캔 결과가 순서대로 완료되는지 확인합니다.
  4. C/S/O 추천 결과를 확인하고 담당자 권한으로 최종 확정합니다.
  5. S등급 문서는 승인 후 전송으로 이동합니다.
  6. 승인 화면에서 의견을 입력하고 승인하면 MOCK Gateway 응답이 표시됩니다.
  7. Post-Inspector 통과 후에만 AI 응답이 보이는지 확인합니다.
  8. 감사 화면에서 메타데이터 전용 PDF를 다운로드합니다.
현재 무료 개발 모드
로컬에서는 GATEWAY_MODE=MOCK으로 실행합니다. OpenAI API 키와 결제 없이 전체 보안 흐름을 시연할 수 있습니다.

TEAM RULES

팀 공유 시 꼭 지킬 것

GitHub에 올리는 것

  • 소스 코드, 테스트, README, DEPLOYMENT.md
  • 프론트 디자인과 공통 컴포넌트
  • API 계약과 운영 체크리스트

GitHub에 올리면 안 되는 것

  • OpenAI API 키, JWT 비밀키, DB 비밀번호
  • .env, 업로드 파일, DB 덤프
  • storage, 가상환경, node_modules
OpenAI 비용 안내
API 키 발급은 무료지만 실제 API 호출은 사용량에 따라 과금됩니다. 지금은 결제하지 않고 MOCK 모드로 개발하고, 실제 AI 연동 테스트나 운영 전환 시에만 별도로 결제합니다. ChatGPT 구독과 API 결제는 서로 별도입니다.
